RESEARCH NOTES

Pricing notes

02 / NOTES
01

Risk-neutral valuation

BSM discounts the expected payoff under the risk-neutral distribution. Volatility controls its spread; the interest rate and dividend yield determine the forward price.

Model formulas
d₁ = [ln(S/K) + (r − q + σ²/2)T] / (σ√T)
d₂ = d₁ − σ√T
C = Se−qTN(d₁) − Ke−rTN(d₂)
P = Ke−rTN(−d₂) − Se−qTN(−d₁)

N is the standard normal cumulative distribution function. The model assumes European exercise, constant volatility and rates, a continuous dividend yield, frictionless markets and continuous trading.

02

Delta changes with spot

Delta measures local price sensitivity. Gamma measures how Delta changes with spot. Near expiry, Delta tends to change more sharply around the strike.

Reading the sensitivities

Select the Near expiry preset and compare the Delta curve. A single Delta estimate becomes less reliable for large spot moves; the scenario charts reprice the option at each point.

Vega and Rho are quoted per percentage point. Theta is quoted per calendar day of elapsed time.

03

Put–call parity

For matching European calls and puts, the price difference equals discounted spot less discounted strike. The residual below checks this relation for the current inputs.

ABOUT THIS PROJECT

Scope and implementation

This project implements European option pricing in the browser. It brings together BSM valuation, analytic Greeks and scenario repricing, with numerical tests for benchmark prices, sensitivities and put–call parity.

View pricing code ↗

Assumptions and limits

Inputs are illustrative, with no live market feed. Values exclude transaction costs, slippage and contract multipliers. Expiry P&L is payoff less the current premium, without financing costs.

Constant volatility does not capture smiles or jumps. The model does not handle early exercise and is not intended for American options or complex structured products.

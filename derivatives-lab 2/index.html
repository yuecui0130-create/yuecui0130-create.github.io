02 / NOTES
01

定价：风险中性视角

BSM 以风险中性分布下的到期收益期望进行贴现。波动率决定分布的离散程度，利率和股息率影响远期价格。

展开模型与公式
d₁ = [ln(S/K) + (r − q + σ²/2)T] / (σ√T)
d₂ = d₁ − σ√T
C = Se−qTN(d₁) − Ke−rTN(d₂)
P = Ke−rTN(−d₂) − Se−qTN(−d₁)

N 为标准正态累积分布函数。假设欧式行权、常数波动率与利率、连续股息率、无摩擦市场和连续交易。

02

风险：Delta 不是常数

Delta 描述局部价格变化，Gamma 描述 Delta 本身的变化。临近到期时，平值附近的 Delta 通常变化更快。

如何阅读敏感度

尝试切换“临近到期”，观察 Delta 曲线。较大价格冲击不能只用一次 Delta 线性外推；本页情景曲线会重新计算完整模型。

Vega 和 Rho 以 1 个百分点为单位；Theta 以每天为单位，表示时间流逝的影响。

03

验证：看涨看跌平价

相同标的、行权价和期限下，看涨与看跌价格差应满足平价关系。这是检查欧式期权定价的一项基础约束。

C − P = Se−qT − Ke−rT

模型边界

参数为可调整的教学情景，不接入实时行情。未计入交易成本、滑点和合约乘数；到期盈亏为收益减去当前权利金，不计权利金融资成本。

常数波动率模型无法反映波动率微笑、跳跃或提前行权，不直接适用于美式期权及复杂结构产品。
